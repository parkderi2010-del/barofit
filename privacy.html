‹ 바로핏으로 돌아가기

개인정보·이용 안내

시행일: 2026년 11월 17일 · 베타 버전 기준

이 문서는 베타 버전의 실제 동작을 기준으로 작성한 초안이에요. 정식 출시와 결제 도입 전에 법률 전문가의 검토를 받아 정식 개인정보 처리방침과 이용약관으로 바꿀 예정이에요.

1. 바로핏은 어떤 서비스인가요

바로핏은 휴대폰 카메라로 운동 동작을 인식해 횟수를 세고 자세에 대한 참고 피드백을 주는 운동 보조 서비스예요. 의료 기기가 아니며, 질병의 진단·치료·예방을 목적으로 하지 않아요.

  • 카메라 판정은 촬영 각도, 조명, 옷차림, 몸이 가려지는 정도에 따라 틀릴 수 있어요. 인식이 불안정하면 판정을 보류해요.
  • 운동 중 통증이나 어지러움이 있으면 즉시 멈추고, 증상이 계속되면 의사나 물리치료사와 상담하세요.
  • 무거운 무게를 다룰 때는 앱의 알림을 참고만 하고, 안전 장비와 보조자를 이용하세요.

2. 카메라 영상은 어떻게 처리되나요

  • 카메라 영상은 이 기기 안에서만 분석돼요. 영상과 사진을 저장하거나 서버로 보내지 않아요. 분석에는 구글의 MediaPipe 자세 인식 기술을 쓰고, 이 기술은 브라우저 안에서 실행돼요.
  • 분석 결과로 나온 관절 위치는 횟수와 자세 점수를 계산하는 데만 쓰고 바로 버려요.
  • "기록 자랑하기"를 누르면 운동 요약 이미지를 만들어 휴대폰의 공유 창에 넘겨요. 어디로 보낼지는 사용자가 직접 골라요. 이 이미지에 카메라 영상은 들어가지 않아요.

3. 어떤 정보를 어디에 저장하나요

바로핏은 현재 회원가입과 서버가 없어요. 아래 정보는 모두 이 기기의 브라우저 저장공간에만 저장되고, 회사(개발자)는 이 정보를 볼 수 없어요.

  • 내 정보: 키, 몸무게, 성별(선택), 운동 경험, 목표, 코치 스타일
  • 운동 기록: 날짜, 운동 종류, 세트·횟수, 무게, 자세 점수, 판정 신뢰도, 몸 상태 응답
  • 설정, 포인트, 배지, 직접 만든 루틴, 모범 동작 기준, 판정 보정 값

키·몸무게·성별은 자세 판정 기준, 추천 무게, 소모 칼로리를 계산하는 데만 써요. 입력하지 않아도 기본 기능은 모두 쓸 수 있어요.

4. 외부로 나가는 연결

화면을 그리고 AI를 실행하려고 아래 곳에서 글꼴과 프로그램 파일을 내려받아요. 이 과정에서 일반적인 웹사이트 접속처럼 기기의 IP 주소와 브라우저 정보가 해당 업체에 전달될 수 있어요. 운동 기록이나 영상은 보내지 않아요.

  • jsDelivr (cdn.jsdelivr.net): 글꼴, AI 실행 파일
  • Google (fonts.googleapis.com, storage.googleapis.com): 글꼴, 자세 인식 모델 파일
  • GitHub Pages: 바로핏 웹사이트 자체
  • 상점의 상품 링크를 누르면 해당 쇼핑몰로 이동하고, 그 이후는 쇼핑몰의 정책을 따라요.

5. 내 정보 확인·삭제

  • 내 정보 수정: 설정 → 내 정보 → 수정
  • 기록 옮기기: 기록 → 공유와 백업 → 기록 내보내기 / 불러오기
  • 전부 지우기: 설정 → 내 데이터 → 모든 데이터 지우기 (되돌릴 수 없어요). 브라우저의 방문 기록·웹사이트 데이터를 지워도 함께 지워져요.

6. 광고와 상품

상점의 일부 링크는 제휴 링크일 수 있으며, 구매 시 바로핏이 수수료를 받을 수 있어요. 제휴 링크는 상점 화면에 표시해요. 현재 광고 영역은 비어 있으며, 광고를 붙이게 되면 이 안내에 광고 업체와 수집 정보를 먼저 밝힐게요.

7. 만 14세 미만 이용자

만 14세 미만은 보호자와 함께 이용해 주세요. 정식 서비스에서 회원가입을 도입하면 법에 따라 보호자 동의 절차를 마련할 예정이에요.

8. 문의

베타 기간 문의와 의견은 바로핏 개발자에게 전달해 주세요. 정식 출시 때 담당자 연락처를 이곳에 적을게요.
